## How to Run
1. Install Java JDK on your system.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Compile the Java file:

   ```Terminal
   javac FileName.java
   ```

5. Run the program:

   ```Terminal
   java ClassName
   ```
